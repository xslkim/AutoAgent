# Migration Guide: v0.x → v1.0

## Overview

v1.0 是 AutoAgent 的首个稳定版本。如果从 Phase 0-3 的早期开发版升级，
以下变更是 breaking 或需要调整的。

---

## 1. Unity Adapter 路径迁移

**Breaking**: Unity adapter 代码从项目根迁移到 `Assets/AutoAgent/` 下。

```
# 旧路径 (v0.x)
adapters/unity/Runtime/Input/EngineInputDriver.cs
adapters/unity/Editor/...

# 新路径 (v1.0)
adapters/unity/Assets/AutoAgent/Runtime/Input/EngineInputDriver.cs
adapters/unity/Assets/AutoAgent/Editor/...
```

**Action**: 更新你的 `.asmdef` 引用路径和 CI 脚本中的文件 glob。

---

## 2. UPM 本地包引用

**Breaking**: fixture 项目通过本地 UPM 包引用 adapter，不再使用直接文件引用。

```json
// fixtures/unity-test-project/Packages/manifest.json
{
  "dependencies": {
    "com.autoagent.runtime": "file:../adapters/unity"
  }
}
```

**Action**: 确保 fixture 项目的 `manifest.json` 包含正确的相对路径引用。
包名统一为 `com.autoagent.runtime`。

---

## 3. input_layer 参数

**新增**: `click` / `drag` / `key_press` MCP 工具现在接受 `input_layer` 参数。

```python
# v1.0 新增
await click(id="btn", input_layer="os")       # OS 级输入 (Windows/macOS/Linux)
await click(id="btn", input_layer="engine")   # 引擎事件层 (默认，向后兼容)
```

**兼容性**: 默认值 `"engine"` 在 wire protocol 中 **不发送**，旧 adapter 不受影响。
OS 层需要在 adapter 侧有对应平台 driver（Win32 / macOS / Linux）。

---

## 4. 视觉回归 API 变更

**新增工具**:
- `compare_lpips_to_baseline` — LPIPS 感知相似度（替代纯 SSIM 的不足）
- `claude_judge_screenshot` — Claude Vision 二次裁决

**Action**: 更新你的 agent prompt 以使用新工具。旧的 `compare_to_baseline` (SSIM)
仍然可用，但推荐配合 LPIPS + Claude Vision 使用。

---

## 5. 防护规则更新

**新增**: `path_whitelist.yml` 规则覆盖范围扩大。

- Unity adapter `.cs` 文件需要匹配 `Assets/AutoAgent/` 路径
- `adapters/unity/Packages/**` 和 `adapters/unity/ProjectSettings/**` 加入
  `review_required` 类别

**Action**: 如果你的自定义 CI 引用了 `path_whitelist.yml`，确保规则是最新的。

---

## 6. CI Runner 要求

**新增**:
- **Windows self-hosted runner**: 需要 Unity 2023.2+ 和 UE 5.x Editor
- **Unity test runner**: fixture 项目 `unity-test-project` 需要本地包解析可用
- **Source audit**: Python 3.12+ + PyYAML

**Action**: 更新 self-hosted runner 的 Unity 和 UE 版本。

---

## 7. Agent Runner 变更

**变更**: agent runner 后端从 Claude API 切换到 opencode + DeepSeek。

**.env.agent 配置**:
```bash
# v0.x (旧)
AGENT_RUNNER=claude-code
ANTHROPIC_API_KEY=sk-ant-...

# v1.0 (新)
AGENT_RUNNER=opencode
DEEPSEEK_API_KEY=sk-...
```

---

## 8. 测试变更

- 平台专属测试使用 `Assert.Ignore` 而非 `Assume.That`（避免 batch mode inconclusive 导致 exit code 2）
- 测试文件需要 `AUTOAGENT_ALLOW_VISUAL` 标记（如涉及 visual 字段写入的测试 setup）
- `Win32InputDriverTests` / `MacInputDriverTests` / `LinuxInputDriverTests` 在非目标平台自动跳过

---

## 9. API 费用追踪

**新增**: `scripts/agent/cost_tracker.py` 记录每日 API 费用到 `state/costs/`。

```bash
python scripts/agent/cost_tracker.py --today     # 查看今日费用
python scripts/agent/cost_tracker.py --limit 5.0  # 设置上限 (USD)
```

---

## 10. 已知 Breaking Changes 汇总

| 变更 | 影响范围 | 向后兼容 |
|------|---------|---------|
| Unity 路径迁移到 `Assets/AutoAgent/` | CI 脚本、IDE 配置 | 否 |
| UPM 本地包引用 | fixture 项目 | 否 |
| `input_layer` 参数 | MCP 工具调用 | **是**（默认 engine，不发送到 wire） |
| LPIPS + Claude Vision 新工具 | agent prompt | **是**（旧 SSIM 工具仍可用） |
| path_whitelist 规则扩展 | CI source audit | **是**（仅新增 allow/review 规则） |
| Agent runner 切换 | 开发者环境 | 否（需要新的 API key） |

---

## 升级检查清单

- [ ] 更新 Unity adapter 代码路径引用
- [ ] 确认 fixture 项目 `manifest.json` 本地包路径正确
- [ ] 更新 agent runner 环境变量 (`.env.agent`)
- [ ] CI self-hosted runner 版本验证 (Unity 2023.2+, UE 5.x)
- [ ] 测试 `input_layer="os"` 在新平台上正常工作
- [ ] 验证 `path_whitelist.yml` 规则覆盖你的项目结构
- [ ] 运行 `pytest scripts/ci/tests/` + `pytest mcp-server/tests/` 确认全绿
